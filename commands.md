1. `git init` — Initializes a Git repository.
2. `git add` — Stages changes for a commit.
3. `git commit` — Saves a snapshot of staged changes.
4. `git status` — Shows the current state of the repository.
5. `git log` — Displays the commit history.
6. `git branch` — Lists branches in the repository.
7. `git push` — Uploads local commits to GitHub.
